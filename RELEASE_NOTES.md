## What's Changed
- The Windows runtime (x64 and x86 WoW64) and GOG Galaxy downloads show real progress in MB and percent. They no longer appear stuck at 0% until the whole file has arrived.
- Interrupted or failed GOG Galaxy downloads are retried and resumed, and a complete setup from an earlier attempt is reused.
- GOG Galaxy's install step shows the elapsed time and Wine's status, and it stops waiting when the setup exits or does not start.
- Updated the application version to 1.6.5 (build 46).
