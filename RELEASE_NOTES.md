## What's Changed
- Epic, GOG, EA and plain .exe programs no longer receive a Steam identity. Madeira published SteamAppId 356400 (Thumper) and its SteamAppPath for every launch that was not a Steam game or a Madeira Dock session, and a game built with Steamworks then looked for a Steam client.
- Updated the application version to 1.6.10 (build 51).
