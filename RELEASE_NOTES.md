## What's Changed
- EA app games without the EA app: sign in to EA, install games from EA's servers and start them; iDeck gets each game's licence and answers it as the EA app would.
- Ubisoft Connect: the official installer is downloaded from Ubisoft; games copied from your PC with iRelay 3.7 start through Ubisoft Connect.
- iRelay connects over the local network (Wi-Fi or Ethernet) instead of a USB cable. Settings > iRelay shows the iPad's address and a pairing code for iRelay 3.7 or later.
- Simpler native runtime: unused native modules removed; one memory-pressure handler.
- Less work while a game runs: the session screen updates only what it shows, native entry points are looked up once, the JIT probe pauses during play and iRelay transfers run below the game.
- Translations simplified: unused strings removed.
- Updated the application version to 1.1 (build 17).
