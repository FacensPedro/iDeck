## What's Changed
### EA app
- When a game does not accept its EA licence it starts ActivationUI.exe, EA's activation window, which cannot run in this runtime (Dragon Age: Inquisition stops this way). That is not fixed in this release. A bug report for an EA game now states what the licence was prepared for: the game's activation library version, the machine hash version and signature form chosen for it, the files in the game's Core folder, and whether the licence was kept, renewed or could not be requested. It also says when the game started ActivationUI.exe.

### Release
- Updated the application version to 1.7.6 (build 58).
