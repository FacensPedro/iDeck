## What's Changed
- Automatically opens StikDebug when GOG, Epic Games or imported Windows executables need JIT before starting.
- Centered the JIT status indicator and removed its redundant title in the main toolbar.
- Improved bug reports with game name, launcher, device identifier and active logical CPU cores.
- Prevented clearing diagnostic logs during active downloads and transfers.
- Improved routing of 32-bit GOG offline installers through the correct Windows compatibility path.
- Expanded native memory protection and executable compatibility diagnostics.
