## What's Changed
### Game language
- The choice offers only Portuguese (Brazil), Spanish and English. When the store lists the game's languages, only those of the three the game has are shown.
- The explanation text under the choice is removed.

### Games
- Fixed Assassin's Creed IV Black Flag and Fallout: New Vegas closing a few seconds after starting, before the first image. The thread-name signal these games send was resumed at an invalid address; it now returns straight to the game.

### Library
- The Ubisoft Connect tab is removed from the library: Ubisoft's download service refuses iDeck's connection, so its games could not be installed from there.

### Settings
- After JIT is prepared, the debugger connection reads "Connected".

### Version
- Updated the application version to 2.16.1 (build 125).
