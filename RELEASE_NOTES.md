## What's Changed
### Wine fonts
- Wine's system fonts (Tahoma, Marlett and the others) are now in the app, in `iDeck.app/fonts`, where Wine looks for them. Before, they were missing and windows drew text with fallback glyphs.

### Ubisoft games
- Ubisoft Connect is installed and run again for every game that ships a Ubisoft launcher DLL (for example Assassin's Creed IV Black Flag). Without the launcher, Black Flag closed by itself about 26 seconds after starting. Ubisoft Connect runs with its own default settings.

### Version
- Updated the application version to 2.8.3 (build 100).
