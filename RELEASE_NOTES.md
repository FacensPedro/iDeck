## What's Changed
- Sign in to Ubisoft with two-factor support and see the account name in Settings.
- Find Install below the sign-in controls and launch the Ubisoft installer directly.
- Close Settings before opening a Windows session so the Metal display can appear.
- Check launcher installation status outside SwiftUI rendering to keep the store screen responsive.
- Find EA app installation below the account controls. The EA store tab now shows where to install its launcher.
- Require the corresponding installed launcher for EA downloads and recognized EA or Ubisoft titles on Steam and Epic. Battlefield 6 is exempt from the EA app requirement.
- Updated the application version to 2.9.3 (build 104).
